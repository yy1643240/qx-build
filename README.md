# Temporary SQ interface probe

Read-only runtime inventory for a user-owned iOS device. It enumerates only known system selector responders and Objective-C type encodings in SpringBoard. It does not read SquidGesture data, license state, preferences, code or resources; it does not invoke selectors. Output: `/var/jb/tmp/touchx-sq-interface-probe.txt`. Uninstall package and respring to remove.
